# เอกสาร Expert Advisors (EAs)

พื้นที่นี้รวมเอกสารของ EA แต่ละตัวใน Repository โดยแยก Strategy Logic และพฤติกรรมเฉพาะ EA ออกจากเอกสาร Framework

## EA ที่มีเอกสาร

- [Grid](Grid/README.md) — EA สำหรับพัฒนา Grid V1; ปัจจุบันเอกสารครอบคลุม Identity, Persistence และการทดสอบส่วนประกอบที่มีอยู่ แต่ยังไม่ใช่ Grid Engine ที่พัฒนาเสร็จสมบูรณ์

## เพิ่ม EA ตัวใหม่

เมื่อเริ่มทำ EA ใหม่ ให้สร้างโฟลเดอร์ `Docs/EAs/<EA-Name>/` พร้อม README ที่ระบุขอบเขต สถานะ และลิงก์ไปยังเอกสารที่มีจริง แล้วเพิ่มรายการในหน้านี้

สร้างเฉพาะเอกสารที่จำเป็นต่อ EA นั้น เช่น:
- `architecture.md` — องค์ประกอบและความสัมพันธ์ของระบบ
- `strategy-logic.md` — เงื่อนไขเข้า/ออกและกฎกลยุทธ์
- `state-machine.md` — สถานะและ Transition หากมี
- `configuration.md` — Inputs และผลกระทบของแต่ละค่า
- `Testing/testing.md` — Test inventory, ขั้นตอนทดสอบ และผลที่ผู้ใช้รายงาน
- `Decisions/` และ `Phases/` — สร้างเมื่อมีการตัดสินใจหรือ Phase ที่ควรเก็บเป็นบันทึกถาวร

ไม่จำเป็นต้องสร้างไฟล์เปล่าทุกประเภทตั้งแต่วันแรก
