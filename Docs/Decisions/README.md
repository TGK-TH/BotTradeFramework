# บันทึกการตัดสินใจด้านการออกแบบ (ADR)

ADR ย่อมาจาก Architecture Decision Record ใช้บันทึกการตัดสินใจที่มีผลต่อโครงสร้างหรือพฤติกรรมของระบบ เพื่อให้กลับมาอ่านแล้วเข้าใจเหตุผลเดิม ไม่ต้องอนุมานจากโค้ดเพียงอย่างเดียว

## รายการ

- [ADR-001: แยก Grid Identity ออกจาก Grid Persistence](ADR-001-grid-identity-and-persistence.md)
- [ADR-002: ใช้ Chart ID เป็นจุดตั้งต้น ไม่ใช่เงื่อนไขการ Restore](ADR-002-chart-id-is-not-persistence-identity.md)

## รูปแบบ ADR

เอกสารแต่ละฉบับควรมี:
- สถานะ: เสนอ / ยอมรับ / แทนที่แล้ว
- บริบทและปัญหา
- ทางเลือกที่พิจารณา
- การตัดสินใจ
- ผลที่ตามมาและข้อจำกัด
